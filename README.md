# 银河很美 · 七夕

> 一封写在星空里的电子情书。

起源于七夕当晚随手拍下的一片银河。比起喊"传承传统文化"的口号，这个项目更想做一件温柔的小事——**把传说还回星空本身**，让年轻人在仰头的瞬间，自己发现：原来我们中国人的浪漫，本来就这么美。

**在线体验**：<https://daka-agent.github.io/DoubleSeventhFestival/>

---

## 体验内容

整个页面是一次约一分钟的纵向滚动旅程：

1. **开篇 · 银河** —— 一张真实的银河照片铺满全屏，标题浮现，流星不时划过
2. **古今对照** —— 左侧古诗原文，右侧现代白话翻译：
   - 《迢迢牵牛星》：「盈盈一水间，脉脉不得语」
   - 秦观《鹊桥仙》：「两情若是久长时，又岂在朝朝暮暮」
3. **「你的想念，是什么型」小测试** —— 6 道日常场景题，测出你的想念人格：
   - 🧵 **织女型** · 把想念织进日常
   - 🐂 **牛郎型** · 想念就要去见
   - 🐦 **鹊鸟型** · 为别人搭桥
   - 🌌 **银河型** · 独自也很辽阔
4. **海报生成** —— 一键生成 1080×1440 竖版朋友圈海报（银河做底图），长按即可保存分享
5. **结语** —— 「想起谁的时候，就抬头。」

## 设计理念

- **不说教**：不喊口号，不讲大道理，陪你看一片银河
- **私人烙印**：全站只用一张实拍银河照，不用模板素材
- **避开大红大金**：深空蓝 `#0B1A35` + 星辉金 `#E8C36A` + 月白，留白与古意点缀
- **无时效表达**：文案不绑定"七夕当晚"，任何时候打开都成立——想念是全年无休的

## 技术实现

纯静态前端，**零框架、零外部依赖、零构建步骤**——手机上秒开，校园网无压力。

```
├── index.html              # 页面结构（三幕故事 + 测试区）
├── css/
│   ├── style.css           # 主样式：调色系统、排版、动效
│   └── quiz.css            # 测试区样式
├── js/
│   ├── main.js             # 流星动效、平滑滚动、分享逻辑
│   ├── quiz-data.js        # 测试题目与人格类型数据
│   └── quiz.js             # 答题状态机 + Canvas 海报生成
└── assets/
    ├── milky-way.jpg       # 实拍银河照片
    └── fonts/              # 霞鹜文楷子集（24 个 woff2 分片）
```

几个值得一提的细节：

- **内嵌霞鹜文楷子集**：按页面实际用字提取字体分片，只保留 24 个 woff2（约 1.3MB），标题与诗句呈现温柔的手写楷体，且完全离线可用
- **微信内置浏览器适配**：海报改为长按保存（`download` 属性在微信里失效）、分享引导走「右上角 ···」、`viewport-fit=cover` 适配刘海屏、弹层锁定背景滚动
- **移动端优先**：`svh` 兜底地址栏问题、iOS 安全区、`prefers-reduced-motion` 尊重系统减弱动效设置
- **分享卡片**：Open Graph 完整配置，转发到微信/朋友圈自动带银河缩略图

## 部署

```bash
git add -A
git commit -m "说明"
git push
```

约一分钟后线上自动更新。

本地预览：

```bash
python -m http.server 5500
# 打开 http://127.0.0.1:5500/
```
